# Cupertino Glass desktop profile

This directory contains the optional desktop profile. See the [repository README](../README.md) for installation, restoration, compatibility limits and test commands, and [third-party notices](THIRD_PARTY.md) for asset licenses.

Native compositor plugins and application adapters are optional and version-pinned. Build them only against matching versions. Preserve `~/.local/state/cupertino-glass` when switching profiles or uninstalling.
